# Bridgectl Add API Skill

This directory contains the `bridgectl-add-api` skill for Gemini CLI.

## Overview

The `bridgectl-add-api` skill enables AI agents to autonomously onboard legacy ERP endpoints into the ERPBridge ecosystem. It follows a strict 6-step workflow to ensure connectivity and high-quality metadata for downstream tool discovery.

## Structure

- `SKILL.md`: Main entry point and workflow instructions.
- `references/`: Detailed documentation for troubleshooting and CLI commands.
- `assets/`: Static resources like YAML templates for MCP tools.

## Specification

This skill adheres to the [Agent Skills Specification](https://agentskills.io/specification).
