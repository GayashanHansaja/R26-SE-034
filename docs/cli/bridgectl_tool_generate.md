## bridgectl tool generate

Auto-generate an MCP tool schema from a registered API or OpenAPI spec

### Synopsis

Create a protocol-compliant MCP tool definition automatically. 
You can generate a tool from an API already registered in bridgectl, 
or point directly to an OpenAPI YAML/JSON file to batch-generate 
definitions for all operations.

```
bridgectl tool generate [flags]
```

### Examples

```
  bridgectl tool generate --api get-invoices
  bridgectl tool generate --api my-erp --openapi ./specs/erp.yaml
```
